## KAV-170: a bot for the chart's three images

Started right after the compact, on his "start whats recomended". No AWS, $0, nothing deployed.

- **A correction to my own KAV-169 write-up.** ADR-0107 and Lab 110 said Dependabot cannot read the chart's values file. Reading its source, it can (any YAML file in a folder it is pointed at); it was never pointed at the chart. Both documents now carry the correction.
- **The real reason for a manifest:** the same three images are named in eleven places across six files, and a bot can read only some. So: one manifest the bot reads (`deploy/third-party-images/Dockerfile.images`, never built), a script that copies its pins into the six files (`scripts/dev/sync_third_party_images.py`), and the pin test now fails on any disagreement. [ADR-0108](../adr/0108-a-bot-watches-the-chart-images-through-one-manifest-and-a-sync-step.md), [Lab 111](../labs/lab-111-a-bot-that-watches-the-chart-images.md), [runbook](../runbooks/third-party-image-bump.md).

The cooldown does not apply to quay.io (Prometheus): no publication date to read. Recorded in ADR-0108.
