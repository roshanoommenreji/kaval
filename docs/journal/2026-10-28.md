# 2026-10-28

## A new idea recorded as future scope: Petti, a box for the cloud (`KAV-99`)

- **Asked:** Roshan asked whether we could build "a container for the cloud": an empty box anyone can put a project into, give a few settings, and have it come up and scale on AWS or another cloud. He wanted a plan and a survey of what exists, with no changes.
- **Researched (2026-10-28):** the box shape already exists as an open standard (Score, CNCF Sandbox), and Radius, Crossplane v2 and kro do the translation, though the last two need Kubernetes. Defang, Encore, HCP Terraform no-code modules and Amazon ECS Express Mode already do "your project into your cloud". The failures teach the most: Wing (a new cloud *language*, $20M) shut down in 2025, and AWS itself retired Proton (2026-10-07) and Copilot CLI (2026-06-12) and closed App Runner to new customers (2026-04-30).
- **Plan agreed:** no new language, no Terraform fork, no Kubernetes needed. Build a small tool on Score's box file, add `size`, `budget` and `cloud` fields, and turn the box into plain OpenTofu. It shows the plan in plain English with its monthly cost and builds only after a human approves. The AI only drafts. Seven gated stages, starting with trying the existing tools (if one fits, use it and stop). Its own repository, **not started until the current Kaval phase closes**.
- **Recorded:** Jira epic `KAV-99` (labels `infra`, `beyond-v1`, the seven stages as acceptance criteria, no stories yet), [future-scope FS-6](../future-scope.md#fs-6--petti-a-box-for-the-cloud), and a line under *Beyond v1* in the roadmap. No ADR: this is a future-scope idea, not a Kaval architecture decision.
