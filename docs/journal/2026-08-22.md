  an AIOps self-healing cluster and a FinOps cost agent. They turned out to be the same
  machine — telemetry, LLM diagnosis, proposed action, human approval, guarded execution,
  audit trail — differing only in which signals feed it.
- Named it **Kaval** (കാവൽ, "the watch").
- Settled the eight decisions that shape everything: AWS only, $25/mo ceiling, hybrid
  k3s + ephemeral EKS, Expo mobile, Gemma 3 1B with Bedrock escalation, 4–6 hrs/week,
  personal Jira Cloud, private repo until v1.

## Learned

- EKS control plane is $73/mo before a single node. NAT Gateway is $32/mo and ALB $18/mo.
  A textbook always-on EKS setup is ~$153/mo — six times the ceiling. The control plane is
  not even the largest line, which was the surprise.
- k3s is CNCF-conformance-certified. Same API, same manifests, same Helm. The 5% that
  differs is the AWS glue — IRSA, managed node groups, ALB controller — which is exactly
  what the Phase 8 chapter is for.

## Decision worth remembering

The first cost estimate assumed always-on from Phase 4, because the brief was "under
$25/mo" — it optimised against the ceiling rather than the wallet. Pausing the node through
Phases 4–6 and only going always-on at Phase 7 cuts the project total from ~$83 to ~$47.
"What fits the budget" and "what's the cheapest version that still works" are different
questions and need asking separately.
