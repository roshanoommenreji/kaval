## Learned

- EKS control plane is $73/mo before a single node. NAT Gateway is $32/mo and ALB $18/mo.
  A textbook always-on EKS setup is ~$153/mo — six times the ceiling. The control plane is
  not even the largest line, which was the surprise.
- k3s is CNCF-conformance-certified. Same API, same manifests, same Helm. The 5% that
  differs is the AWS glue — IRSA, managed node groups, ALB controller — which is exactly
  what the Phase 8 chapter is for.
- Ollama is already installed on this machine. Phase 1 is closer than expected.
- `make`, `jq`, `gitleaks`, `opa`, `k3d` and `flux` are all missing. Lab 00 covers them.

## Decisions worth remembering

Claude's first cost estimate assumed always-on from Phase 4 because the brief was
"under $25/mo" — it optimised against the ceiling rather than the wallet. Pausing the node
through Phases 4–6 and only going always-on at Phase 7 cuts the project total from ~$83 to
~$47. Worth asking "what's the cheapest version that still works" as a separate question
from "what fits the budget".
