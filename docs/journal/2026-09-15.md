was, but the review surfaced three real issues rather than a clean pass:

1. **`infra/envs/prod` had no `outputs.tf`.** The budget module defines its own outputs, but a

## A genuinely dumb Windows gotcha, documented so nobody else loses ten minutes to it

`aws logs tail "/aws/lambda/$FN" --profile kaval` failed on Git Bash with a confusing
`InvalidParameterException` claiming the log group name failed a regex — the string was clean
(checked with `od -c`, no hidden characters). Actual cause: MSYS silently rewrites a leading-`/`
argument into a Windows path before it reaches `aws.exe`. Fix is `MSYS_NO_PATHCONV=1` prefixed
onto the command. Added directly to Lab 01 so a stranger on Windows doesn't hit the same wall.
